\section{Global Assembly}
\label{sec:global_assembly}

\begin{center}
\code{bionetflux.core.lean\_global\_assembly} \quad(849 lines)
\end{center}

The \code{GlobalAssembler} orchestrates the element loop, constraint
enforcement, and DOF bookkeeping that yield the global Newton residual
and Jacobian.

% ------------------------------------------------------------------
\subsection{DOF Structure}

The global solution vector is partitioned as
\[
  \mathbf{x} = \bigl[\underbrace{U^{(0)},\;\ldots,\;U^{(D-1)}}_{\text{trace DOFs}} \;\big|\;
                \underbrace{\lambda_0,\;\ldots,\;\lambda_{M-1}}_{\text{multipliers}}\bigr],
\]
where $D$ is the number of domains and $M = \sum_c n_c$ is the total multiplier count from all constraints.
Within each domain block $U^{(i)}$, the trace unknowns are ordered equation-major:
$\bigl[u^{(i)}_0,\ldots,u^{(i)}_{N_i},\;\varphi^{(i)}_0,\ldots,\varphi^{(i)}_{N_i},\;\ldots\bigr]$.

\subsection{assemble\_residual\_and\_jacobian}

\begin{lstlisting}[language=Python, caption={Core assembly method}]
def assemble_residual_and_jacobian(
    self, global_solution: np.ndarray,
    forcing_terms: List[np.ndarray],
    static_condensations: List,
    time: float
) -> Tuple[np.ndarray, np.ndarray]:
    """Returns (residual, jacobian) of size total_dofs."""
\end{lstlisting}

\noindent The method:
\begin{enumerate}
  \item Extracts per-domain trace vectors from \code{global\_solution}.
  \item Calls \code{domain\_flux\_jump} for each domain.
  \item Scatters each domain's $F$ and $JF$ into the global residual/Jacobian.
  \item If a \code{ConstraintManager} is present:
    \begin{enumerate}[label=(\alph*)]
      \item Adds multiplier contributions to the trace block of the residual.
      \item Calls \code{constraint\_manager.compute\_constraint\_residuals()} for the multiplier block.
      \item Fills the constraint Jacobian entries via \code{\_add\_constraint\_jacobian\_contributions}.
    \end{enumerate}
\end{enumerate}
