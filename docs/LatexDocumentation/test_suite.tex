\section{Test Suite}
\label{sec:test_suite}

Tests live in the \code{tests/} directory and are driven by \textbf{pytest}.
The configuration in \code{pytest.ini} defines three custom markers:
\code{slow}, \code{integration}, and \code{unit}.

\begin{lstlisting}[caption={Running the test suite}]
# From the repository root:
pip install -e .         # editable install (one-time)
pytest                   # run all tests
pytest -m "not slow"     # skip slow tests
pytest tests/test_geometry.py -v   # single file, verbose
\end{lstlisting}

\subsection{Built-in Self-Tests}

Several classes contain a \code{test() -> bool} method that can be called
independently of pytest:

\begin{itemize}
  \item \code{BulkData.test()}: shape, NaN, trace matrix, round-trip.
  \item \code{BulkDataManager.test(problems, discretizations, static\_condensations)}: 9 sub-tests.
  \item \code{GlobalAssembler.test(problems, discretizations, static\_condensations)}: DOF structure and assembly.
  \item \code{MinimalErrorEvaluator.test()}: mock-based error computation.
  \item \code{test\_domain\_flux\_jump(verbose=True)}: standalone function in \code{flux\_jump.py}.
\end{itemize}
