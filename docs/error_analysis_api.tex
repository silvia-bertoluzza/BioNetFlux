\section{Error Analysis}
\label{sec:error_analysis}

Two modules provide error evaluation against analytical solutions:

\begin{center}
\code{bionetflux.core.minimal\_error\_evaluator} \quad(549 lines) \\
\code{bionetflux.analysis.error\_evaluation} \quad(1242 lines)
\end{center}

% ------------------------------------------------------------------
\subsection{MinimalErrorEvaluator}

A lightweight, stateless evaluator.

\begin{lstlisting}[language=Python, caption={MinimalErrorEvaluator constructor}]
class MinimalErrorEvaluator:
    def __init__(self):
        pass  # No stored state
\end{lstlisting}

\noindent All computation is done through method arguments:

\begin{longtable}{p{7.5cm}p{7cm}}
\toprule
\textbf{Method} & \textbf{Description} \\
\midrule
\code{compute\_trace\_error(trace\_solutions, problems, discretizations, time) -> dict} & Nodal $L^2$ and $L^\infty$ error per equation per domain \\
\code{compute\_bulk\_error(bulk\_solutions, problems, discretizations, time) -> dict} & Element-wise $L^2$ error against analytically projected coefficients \\
\code{compute\_flux\_error(flux\_solutions, problems, discretizations, static\_condensations, time) -> dict} & Flux-polynomial $L^2$ error, respecting per-equation flux orders \\
\code{test() -> bool} & Self-test with mock objects \\
\bottomrule
\end{longtable}

Analytical solutions are read from \code{problem.solution[eq]} (trace),
\code{problem.force[eq]} (bulk), and \code{problem.flux\_solution[eq]}
(flux)---each a callable $f(s,t)$.

\begin{longtable}{p{7.5cm}p{7cm}}

\midrule
