\section{Introduction}
\label{sec:introduction}

\bionetflux{} (version 1.0.0) is a Python framework for simulating biological transport phenomena on complex one-dimensional networks. Built on a Hybridizable Discontinuous Galerkin (HDG) approach, the framework solves coupled partial differential equations (PDEs) on multi-arc (branch/channel) network topologies, with particular focus on:

\begin{itemize}
    \item \textbf{Keller-Segel chemotaxis models}: Two-equation systems ($u$, $\varphi$) modeling cell migration driven by chemical gradients.
    \item \textbf{Organ-on-Chip systems}: Four-equation systems ($u$, $\omega$, $v$, $\varphi$) modeling multi-compartment microfluidic devices with tumor suppression and immune cell dynamics.
    \item \textbf{Multi-arc networks}: Complex geometries including grid networks, labyrinth structures, and mazes loaded from CSV data.
\end{itemize}

\begin{notebox}
Throughout the code the word \code{Domain} is used as a synonym of \code{Arc} (a single 1D segment of the network).
\end{notebox}

\subsection{Key Features}

\begin{itemize}
    \item \textbf{Multi-arc support}: Handle complex network topologies with arbitrary arc connections via the \code{DomainGeometry} class.
    \item \textbf{Arbitrary equation count}: Parametric handling of the number of equations per arc (\code{neq}).
    \item \textbf{TOML configuration}: Problem parameters, initial conditions, boundary conditions, and force functions specified via TOML configuration files with a function resolution system.
    \item \textbf{Flexible constraints}: Dirichlet, Neumann, Robin boundary conditions and Kedem-Katchalsky, trace-continuity junction conditions.
    \item \textbf{Static condensation}: Efficient element-level solution via the \code{StaticCondensationFactory} pattern, mapping problem types to specific implementations.
    \item \textbf{Time evolution}: Implicit Euler time stepping with standard, line-search, and damped Newton solvers; adaptive time step control.
    \item \textbf{Visualization}: 2D curve plots, 3D flat views, bird's eye network views, and geometry index plots via \code{LeanMatplotlibPlotter}.
    \item \textbf{Error analysis}: Trace, bulk, and flux error evaluators with convergence rate computation.
    \item \textbf{Extensibility}: New problem classes require only a problem module exposing \code{create\_global\_framework()} and a corresponding \code{StaticCondensationBase} subclass.
\end{itemize}

\subsection{Dependencies}

\bionetflux{} requires Python $\ge$ 3.11 and depends on:
\begin{itemize}
	\item \code{numpy} $\ge$ 1.24.0 --- array computation and linear algebra
	\item \code{matplotlib} $\ge$ 3.6.0 --- visualization
	\item \code{sympy} $\ge$ 1.12 --- symbolic computation for elementary matrices and expression parsing
	\item \code{tomli} $\ge$ 2.0.0 --- TOML parsing (only for Python $<$ 3.11; Python 3.11+ uses the built-in \code{tomllib})
\end{itemize}

\section{Example Applications}
\label{sec:examples}

The \code{examples/} directory contains complete runnable scripts demonstrating the framework.  The two primary examples are summarized below.

\subsection{Keller-Segel Evolution}

File: \code{examples/evolution\_example\_ks.py}

\begin{lstlisting}[language=Python, caption={Keller-Segel example (simplified excerpt)}]
from setup_solver import quick_setup
from bionetflux.time_integration.time_stepper import TimeStepper
from bionetflux.visualization.lean_matplotlib_plotter import LeanMatplotlibPlotter

# 1. Setup
config_file = "config/ks_parameters.toml"
setup = quick_setup(
    problem_module="bionetflux.problems.ks_problem",
    validate=True,
    config_file=config_file
)

# 2. Time stepper
stepper = TimeStepper(setup, verbose=True)
solution, bulk_data = stepper.initialize_solution()

# 3. Evolve
dt = setup.global_discretization.dt
T  = setup.global_discretization.T
current_time = 0.0
while current_time < T:
    result = stepper.advance_time_step(solution, bulk_data, current_time, dt)
    if result.converged:
        solution = result.updated_solution
        bulk_data = result.updated_bulk_data
        current_time += dt

# 4. Visualize
traces, _ = setup.extract_domain_solutions(solution)
plotter = LeanMatplotlibPlotter(
    setup.problems,
    setup.global_discretization.spatial_discretizations
)
plotter.plot_2d_curves(traces, title="Final State")
plotter.show_all()
\end{lstlisting}

\subsection{Organ-on-Chip with Maze Geometry}

File: \code{examples/evolution\_maze\_ooc.py}

\begin{lstlisting}[language=Python, caption={OoC maze example (simplified excerpt)}]
from setup_solver import quick_setup
from bionetflux.time_integration.time_stepper import TimeStepper, AdaptiveTimeStepper
from bionetflux.geometry.domain_geometry import create_maze_geometry

# 1. Build maze geometry from CSV data
geometry = create_maze_geometry(
    data_dir="examples/maze_2_data",
    length=50.0
)

# 2. Setup with custom geometry
setup = quick_setup(
    problem_module="bionetflux.problems.ooc_problem",
    validate=True,
    config_file="config/ooc_parameters.toml",
    geometry=geometry
)

# 3. Adaptive time stepping
stepper = TimeStepper(setup, verbose=True)
adaptive = stepper.get_adaptive_stepper(
    dt_min=setup.global_discretization.dt * 1e-4,
    dt_max=setup.global_discretization.dt
)

solution, bulk_data = stepper.initialize_solution()
dt = setup.global_discretization.dt
current_time = 0.0

while current_time < setup.global_discretization.T:
    result, dt = adaptive.advance_time_step_adaptive(
        solution, bulk_data, current_time, dt
    )
    if result.converged:
        solution = result.updated_solution
        bulk_data = result.updated_bulk_data
        current_time += dt
\end{lstlisting}
